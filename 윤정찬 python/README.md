# 프롬프트 관리 프로그램

터미널 환경에서 실행되는 간단한 AI 프롬프트 관리 프로그램입니다. 자주 사용하는 프롬프트를 카테고리별로 등록하고, 검색하거나 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

1. Python이 설치되어 있어야 합니다. (Python 3.x 권장)
2. 터미널(또는 명령 프롬프트)에서 아래 명령어를 실행합니다.

```bash
python 과제.py
```

3. 실행 후 화면에 표시되는 메뉴 번호를 입력해 원하는 기능을 사용합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다. |
| 2 | 프롬프트 목록 보기 | 등록된 모든 프롬프트를 번호, 제목, 카테고리, 즐겨찾기 여부와 함께 보여줍니다. |
| 3 | 카테고리별 조회 | 현재 등록된 카테고리 목록을 보여주고, 선택한 카테고리에 속한 프롬프트만 조회합니다. |
| 4 | 프롬프트 검색 | 입력한 검색어가 제목 또는 내용에 포함된 프롬프트를 찾아 보여줍니다. |
| 5 | 프롬프트 상세 보기 | 번호를 선택해 해당 프롬프트의 제목, 카테고리, 즐겨찾기 상태, 전체 내용을 확인합니다. |
| 6 | 즐겨찾기 추가/해제 | 프롬프트 번호를 선택해 즐겨찾기 상태를 켜거나 끕니다. |
| 7 | 즐겨찾기 목록 보기 | 즐겨찾기로 등록된 프롬프트만 모아서 보여줍니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

## 등록된 프롬프트 카테고리

프로그램 실행 시 다음 6개의 기본 카테고리 중에서 선택하거나, 직접 새로운 카테고리를 입력할 수 있습니다.

- **텍스트 생성**: 글쓰기, 요약, 번역 등 텍스트 관련 프롬프트
- **이미지 생성**: 이미지 생성 AI에 사용할 프롬프트
- **영상 생성**: 영상 생성 AI에 사용할 프롬프트
- **페르소나**: 특정 역할(면접관, 튜터 등)을 부여하는 프롬프트
- **자동화**: 반복 작업 자동화를 위한 프롬프트
- **기타**: 위 카테고리에 속하지 않는 프롬프트

카테고리 선택 화면에서 "0. 직접 입력"을 선택하면 목록에 없는 카테고리를 자유롭게 등록할 수도 있습니다.

## 초기 등록 데이터

프로그램을 처음 실행하면 아래 3개의 예시 프롬프트가 기본으로 등록되어 있습니다.

1. **블로그 글쓰기 도우미** (텍스트 생성)
2. **썸네일 이미지 프롬프트** (이미지 생성, 즐겨찾기 ⭐)
3. **영어 면접 페르소나** (페르소나)
