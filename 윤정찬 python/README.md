# 프롬프트 관리 프로그램

AI 프롬프트를 등록, 조회, 검색, 즐겨찾기까지 관리할 수 있는 콘솔(터미널) 기반 파이썬 프로그램입니다.

## 주요 기능

- **프롬프트 추가**: 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다.
- **프롬프트 목록 보기**: 등록된 모든 프롬프트를 번호, 제목, 카테고리, 즐겨찾기 여부와 함께 출력합니다.
- **카테고리별 조회**: 등록된 카테고리 목록을 보여주고, 선택한 카테고리에 속한 프롬프트만 필터링해서 보여줍니다.
- **프롬프트 검색**: 제목과 내용에서 키워드를 검색합니다(대소문자 구분 없음).
- **프롬프트 상세 보기**: 번호를 입력하면 해당 프롬프트의 제목/카테고리/즐겨찾기/내용을 상세히 보여줍니다.
- **즐겨찾기 추가/해제**: 번호를 입력해 즐겨찾기 상태를 토글(⭐ 표시)합니다.
- **즐겨찾기 목록 보기**: 즐겨찾기된 프롬프트만 모아서 보여줍니다.

## 실행 방법

```bash
python 과제.py
```

프로그램을 실행하면 기본 예시 프롬프트 3개가 자동으로 등록된 상태로 시작됩니다.

## 메뉴 구성

```
====== 프롬프트 관리 프로그램 ======
1. 프롬프트 추가
2. 프롬프트 목록 보기
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가/해제
7. 즐겨찾기 목록 보기
0. 종료
==================================
```

원하는 메뉴 번호를 입력해 기능을 실행하고, `0`을 입력하면 프로그램이 종료됩니다.

## 카테고리 목록

프롬프트 추가 시 아래 카테고리 중 하나를 선택하거나, 직접 입력할 수 있습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타
- (0번 선택 시 직접 입력)

## 데이터 구조

각 프롬프트는 다음과 같은 형태의 딕셔너리로 저장됩니다.

```python
{
    "title": "프롬프트 제목",
    "content": "프롬프트 내용",
    "category": "카테고리명",
    "favorite": False
}
```

> ⚠️ 현재 데이터는 프로그램 실행 중에만 메모리에 저장되며, 프로그램을 종료하면 사라집니다(파일 저장 기능 없음).

## 주요 함수

| 함수명 | 역할 |
|---|---|
| `create_default_prompts()` | 기본 예시 프롬프트 3개 생성 |
| `show_menu()` | 메뉴 화면 출력 |
| `get_non_empty_input(message)` | 빈 값이 입력되지 않을 때까지 재입력 요구 |
| `choose_category()` | 카테고리 선택(목록 선택 또는 직접 입력) |
| `add_prompt(prompts)` | 새 프롬프트 추가 |
| `display_prompt_summary(index, prompt)` | 프롬프트 한 줄 요약 출력 |
| `show_list(prompts)` | 전체 프롬프트 목록 출력 |
| `show_categories(prompts)` | 카테고리별 조회 |
| `search_prompt(prompts)` | 키워드로 프롬프트 검색 |
| `show_prompt_detail(prompts)` | 프롬프트 상세 정보 출력 |
| `toggle_favorite(prompts)` | 즐겨찾기 상태 토글 |
| `show_favorites(prompts)` | 즐겨찾기 목록 출력 |
| `main()` | 프로그램 메인 루프 |

## 요구 사항

- Python 3.x (별도의 외부 라이브러리 불필요)

## 향후 개선 아이디어

- 프롬프트 데이터를 파일(JSON 등)로 저장/불러오기
- 프롬프트 수정/삭제 기능
- 카테고리 관리(추가/삭제) 기능
